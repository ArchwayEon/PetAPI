# PetAPI

PetAPI is a small ASP.NET Core Web API for managing a list of pets. It was built as a teaching example for CSCI 3110, so the code is kept simple and commented to show how a web API is put together.

The API stores its data in a SQLite database and exposes five endpoints for reading, creating, updating, and deleting pets.

## Features

- Get all pets
- Get one pet by id
- Add a new pet
- Update an existing pet
- Delete a pet
- The database is created from migrations and seeded with five sample pets

## Technology

- [.NET 10](https://dotnet.microsoft.com/) and ASP.NET Core
- [Entity Framework Core 10](https://learn.microsoft.com/ef/core/) with the SQLite provider
- SQLite, stored in the `Data` folder

## Project Layout

| Path | Purpose |
|------|---------|
| `Controllers/PetController.cs` | The API endpoints. Handles HTTP requests and responses. |
| `Services/IPetRepository.cs` | The interface the controller uses to read and write pets. |
| `Services/DbPetRepository.cs` | The implementation of `IPetRepository` that uses the database. |
| `Services/ApplicationDbContext.cs` | The Entity Framework database context, including the seed data. |
| `Models/Entities/Pet.cs` | The `Pet` class (`Id`, `Name`, `Weight`). |
| `Migrations/` | Database migrations generated by Entity Framework. |
| `Data/` | Location of the SQLite database file (`pet.db`). |
| `Program.cs` | Application setup: services, database connection, and routing. |
| `appsettings.json` | Settings, including the database connection string. |

## Getting Started

### Prerequisites

- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
- The Entity Framework command-line tool, needed only to create or apply migrations:

  ```bash
  dotnet tool install --global dotnet-ef
  ```

### 1. Restore the packages

From the project folder (the one containing `PetAPI.csproj`):

```bash
dotnet restore
```

### 2. Create the database

Apply the migrations. This creates `Data/pet.db` with the `Pets` table and the five sample pets:

```bash
dotnet ef database update
```

If you delete `Data/pet.db`, run this command again to rebuild it.

### 3. Run the application

```bash
dotnet run
```

Or start it from Visual Studio, VS Code, or Rider. The `http` profile in `Properties/launchSettings.json` uses `http://localhost:5083`.

## Using the API

Base URL: `http://localhost:5083/api/pet`

| Method | URL | Body | Success response |
|--------|-----|------|------------------|
| GET | `/api/pet/all` | none | `200 OK` with an array of pets |
| GET | `/api/pet/one/{id}` | none | `200 OK` with one pet, or `404 Not Found` |
| POST | `/api/pet/create` | form-data: `Name`, `Weight` | `201 Created` with the new pet |
| PUT | `/api/pet/update` | form-data: `Id`, `Name`, `Weight` | `204 No Content`, or `404 Not Found` |
| DELETE | `/api/pet/delete/{id}` | none | `204 No Content`, or `404 Not Found` |

A pet looks like this in JSON:

```json
{
  "id": 1,
  "name": "Buddy",
  "weight": 30.5
}
```

### Examples with curl (bash, zsh, macOS, Linux)

```bash
# Get all pets
curl http://localhost:5083/api/pet/all

# Get one pet
curl http://localhost:5083/api/pet/one/2

# Create a pet (form-data)
curl -X POST -F "Name=Luna" -F "Weight=6.5" http://localhost:5083/api/pet/create

# Update a pet (form-data; Id says which pet to change)
curl -X PUT -F "Id=1" -F "Name=Buddy" -F "Weight=31" http://localhost:5083/api/pet/update

# Delete a pet
curl -X DELETE http://localhost:5083/api/pet/delete/3
```

### Examples with curl.exe (Windows PowerShell)

In PowerShell, `curl` is an alias for `Invoke-WebRequest`, which accepts different arguments. Type `curl.exe` to run the real curl program instead.

```powershell
# Get all pets
curl.exe http://localhost:5083/api/pet/all

# Get one pet
curl.exe http://localhost:5083/api/pet/one/2

# Create a pet (form-data)
curl.exe -X POST -F "Name=Luna" -F "Weight=6.5" http://localhost:5083/api/pet/create

# Update a pet (form-data; Id says which pet to change)
curl.exe -X PUT -F "Id=1" -F "Name=Buddy" -F "Weight=31" http://localhost:5083/api/pet/update

# Delete a pet
curl.exe -X DELETE http://localhost:5083/api/pet/delete/3
```

## Changing the Database

When you change the `Pet` class or the `ApplicationDbContext`, create a new migration and apply it:

```bash
dotnet ef migrations add <MigrationName>
dotnet ef database update
```

## Troubleshooting

- **"no such table: Pets"**: the database has not been created. Run `dotnet ef database update`.
- **The pets are not the ones you expected**: your test changes are stored in `Data/pet.db`. Delete the file and run `dotnet ef database update` to start over with the sample data.
- **Port already in use**: change `applicationUrl` in `Properties/launchSettings.json`, or stop the other program that is using the port.
